# Политика подписи кода

Этот документ описывает, как устроена (и в перспективе будет устроена) подпись
`PhotoArchive.exe` — требование, которое проверяет SignPath Foundation при рассмотрении
заявки на бесплатную подпись для open-source проектов, но он полезен и сам по себе, как
ответ на вопрос «кому доверять этот `.exe`».

## Кто может выпустить релиз

- Единственный мейнтейнер проекта — аккаунт GitHub [`vo1012`](https://github.com/vo1012).
  Больше ни у кого нет прав push/тегирования в этот репозиторий.
- Релиз возможен только через создание тега вида `vX.Y.Z` в этом репозитории — сборка
  `.exe`/`.zip` и их публикация в [GitHub Releases](https://github.com/vo1012/PhotoArchive/releases)
  автоматические, ручной загрузки файлов в обход этого процесса нет.

## Откуда берётся `.exe`

- Единственный источник сборки — [GitHub Actions](https://github.com/vo1012/PhotoArchive/actions)
  этого репозитория, workflow [`ci.yml`](./.github/workflows/ci.yml) (задача `build`,
  `runs-on: windows-latest`, PyInstaller). Локально собранные `.exe` в релиз не попадают.
- Исходный код, из которого собирается `.exe` — открытый, под [Apache License 2.0](./LICENSE),
  этот же репозиторий. Помимо него в сборку включены четыре сторонних бинарника
  (exiftool/7-Zip/ffmpeg/UnRAR) — их лицензии и условия перечислены в
  [`THIRD_PARTY_LICENSES.md`](./THIRD_PARTY_LICENSES.md).

## Роли

Проект однопользовательский: один и тот же человек (мейнтейнер) пишет код, проверяет
изменения перед релизом и создаёт тег релиза — отдельных ролей «автор/ревьюер/утверждающий»
не предусмотрено ввиду масштаба проекта.

## Подпись через SignPath Foundation

Проект подал заявку на бесплатную подпись `.exe` через программу
[SignPath Foundation для open-source проектов](https://signpath.org/). Если заявка одобрена:

- Подписывающая сторона в диалогах Windows (SmartScreen, свойства файла) будет указана как
  **«SignPath Foundation»**, а не как имя мейнтейнера или название проекта — так устроена
  сама программа, доверие подтверждается через связь с этим репозиторием, а не через личность.
- Подписывается только `.exe`, собранный доверенной сборочной системой (GitHub Actions этого
  репозитория, см. выше) — вручную собранные копии не подписываются.

До одобрения заявки `.exe` не подписан — при первом запуске Windows может показать
предупреждение SmartScreen; это ожидаемо для новых непроверенных программ, а не признак
проблемы (исходный код открыт и доступен для проверки).
